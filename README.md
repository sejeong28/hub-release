# 🦖 Hub

화면 구석에 떠 있는 공룡 캐릭터 런처예요.

- 공룡을 누르면 자주 쓰는 **앱·폴더·웹사이트 바로가기**가 펼쳐져요.
- 정해 둔 시간에 **말풍선으로 할 일**을 알려줘요. (매일 / 매주 / 매월 / 매월 마지막 월요일부터 며칠 등)
- 숨 쉬고, 깜빡이고, 꼬리 흔들고, 졸고, 기지개 켜며 혼자 놀아요.
- **내 캐릭터 그림**으로 바꿀 수도 있어요. (정면 한 장이면 충분)

## 설치
1. 오른쪽 **Releases**에서 최신 버전의 `Hub.zip`을 받아요.
2. 압축을 풀고 `Hub.app`을 **응용 프로그램** 폴더로 옮겨요.
3. `Hub.app`을 **우클릭 → 열기** (처음 한 번만 확인 창이 떠요)
   - 그래도 안 열리면: 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기"
4. 화면 오른쪽 아래에 공룡이 나타나요! 공룡을 **우클릭 → 설정…**에서 바로가기·알림·캐릭터를 바꿀 수 있어요.

## 업데이트
새 버전이 나오면 공룡이 말풍선으로 알려줘요. 누르면 알아서 바꿔 끼우고 다시 켜져요.
설정·바로가기·알림·내 캐릭터는 그대로 남아요.

## 참고
- macOS 14(소노마) 이상, 인텔·애플 칩 모두 지원
- 설정과 알림은 내 맥에만 저장돼요. 인터넷은 새 버전 확인할 때만 써요.
